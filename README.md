# お絵かき合体（Web版）

1つのお題を人数で分けて描き、最後に1枚に合体するゲーム。線で描く。ビルドは不要（HTML と JavaScript だけ）。

## 遊び方の流れ（企画の図のとおり）

- シングル → 難易度（初級／中級／上級）→ CPUと合体：2つのパートの片方だけを描く。もう片方は CPU が自動で描く（見本の絵のその部分）
- 対戦 → 難易度 → 人数（2〜5人）→ オンライン：同じ難易度・同じ人数で待っている部屋に自動で入る。なければ部屋を作って待つ
- フレンド → カギを入力 → 対戦：4けたのカギで友だちの部屋に入る
- フレンド → 部屋を作る → 難易度 → 人数とカギ：人数（2〜5の半角数字で入力）と4けたのカギを自分で決めて、部屋を作る

部屋では、決めた人数がそろって全員が「準備OK」を押すと始まる。絵は、決めた人数で分ける。描く時間は180秒。

分け方は、まっすぐな線だけ。1人ぶんの紙は 1000×500（上下）か 500×1000（左右）で、人数ぶんをならべる。

- 2人：上下、左右、ななめ（ななめは中級と上級だけ）
- 3〜5人：上から順（たてに長い絵になる）か、左から順（横に長いお題のとき）

合体のとき、つなぎめで絵のはばと位置が合うように、小さいほうの絵を大きいほうに合わせて自動で大きくする（2倍まで）。
点数は「そっくり度」（100点満点）：合体した絵が、見本にどれだけ近いか（形4割、色の割合2割、色の場所4割）。シングルは、自分が描いたパートだけを見本の同じパートとくらべる。
つなぎめがどれだけ合っていたか（つながり度）も、小さく出す。

お題の文字は、中学3年生までに習う漢字（常用漢字）は漢字で書く。動物のお題には、描く向き（正面・左向き・上から見た形）をそえる。

お題は300こ（初級100、中級100、上級100）。同じお題は、全部出るまでくり返さない。どのお題にも見本の絵（おてほん）があり、ゲームが始まると最初の5秒だけ見える（描く画面では見えない）。合体のあとには、左上に出る。

お題の種類は、食べ物・動物・もの・植物（日本でよく見る花や木）・季節（クリスマス、ハロウィン）。
「サンタぼうしをかぶったネコ」のような組み合わせお題も出る（ことば＋お題）。組み合わせるのは食べ物・動物・ものだけで、植物と季節のお題はそのまま出す。
12月はクリスマス、10月はハロウィンのことばが出やすい。

見本の絵は `samples/` フォルダに種類ごとのファイルで置いてあり、合体のときにそのお題のファイル1つだけを読みこむ（最初の読みこみを軽くするため）。

道具は、ペン・ぬりつぶし・消しゴム。

## 手元で動かす

```bash
python -m http.server 5173 --directory oekaki-web
```

ブラウザで `http://localhost:5173` を開く。`?sec=15` をつけると、描く時間を15秒にできる（確認用）。`?trial=1` をつけると、Supabase を使わずにお試しモードで動く。

## Supabase をつなぐ

設定前は「お試しモード」で、対戦とフレンドは同じブラウザの別タブ同士だけつながる。

1. Supabase でプロジェクトを作る
2. SQL Editor に `supabase/schema.sql` を全部貼って Run を押す
3. Project Settings → API の Project URL と anon public key を `config.js` に貼る

`service_role` の鍵は貼らない。

## 守りのしくみ

サーバー（Supabase）側：

- `rooms` の表は、外から直接読む・書く・消すことができない。`schema.sql` の窓口の関数だけが使える
- 人数の更新と部屋を閉じる操作は、部屋を作った人だけが持つ合言葉が必要
- カギは4けた（9000通り）。まちがったカギを同じ接続元から1分に10回入れると、しばらく受けつけない
- 部屋を作れるのは、同じ接続元から10分に20部屋まで。使われている部屋が全体で500を超えたら断る

部屋の中（ブラウザ同士）：

- プレイヤーごとに、ページを開くたびに鍵のペアを作る。id は公開する鍵から計算するので、他人になりすませない（`sec.js`）
- 「始める」と「パート」のメッセージには署名をつける。署名が合わないもの、部屋にいない人からのものは捨てる
- 「始める」の中身も確かめる：お題と分け方は決まった一覧の中だけ。自分が「準備OK」を押していないラウンドには参加しない
- パートは本人のぶんだけを受けつけ、最初に届いた1つだけを使う（あとから書きかえられない）
- 席は来た順。あとから来た人が、前からいる人の席をうばったり追い出したりはできない

ページ：

- プログラムは自分のサイトのものだけを動かす（Content-Security-Policy）。通信の部品も `vendor/` に置いてある
- なまえなどの文字は、いつも「ただの文字」として表示する（プログラムとして動かない）

防げないこと：

- だれでも入れる「対戦」の部屋に、変な絵を描く人や、わざと何もしない人が来ること
- 部屋に入った人が、にせの参加者を何人も入れて席をうめること
- 大量の通信を送って、Supabase の無料枠を使い切らせること（Supabase 側の制限で止まるが、その間は遊べなくなる）

## ファイル

- `app.js`：画面とゲームの流れ
- `draw.js`：描くキャンバス、ぬりつぶし、分け方（レイアウト）、合体（自動でつなげる）、点数
- `net.js`：部屋の通信（Supabase とお試しモード）
- `sec.js`：なりすまし対策（鍵のペアと署名）
- `vendor/supabase.js`：通信の部品（supabase-js 2.45.4 をそのまま置いたもの）
- `fx.js`：効果音、紙ふぶき、らくがきが流れる背景
- `card.js`：保存・シェアする画像（絵に背景・タイトル・お題・点数・見本・描いた人をつける）
- `ogp.png`：URL を貼ったときに出る紹介カードの画像（`tools/make_ogp.py` で作る）
- `style.css`：見た目（色、ボタン、アニメーション）
- `samples.js`：見本の絵（おてほん）を描く道具と、読みこむ関数
- `samples/`：見本の絵そのもの（300こ。種類ごとのファイル）
- `samples/mods.js`：組み合わせお題の見本を作る（もとの絵に、帽子・リボン・雪などの飾りを描き足す）
- `tools/check_samples.mjs`：全部のお題に見本があるかを調べる（`node tools/check_samples.mjs`）
- `tools/sheet.html`：見本の絵を一覧で見る（`http://localhost:5173/tools/sheet.html?f=plant`）
- `topics.js`：難易度とお題300こ、組み合わせお題、同じお題をくり返さないしくみ
- `config.js`：Supabase の接続先
- `supabase/schema.sql`：Supabase に作るテーブルと関数
