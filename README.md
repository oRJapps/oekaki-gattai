# お絵かき合体（Web版）

1つのお題を人数で分けて描き、最後に1枚に合体するゲーム。線で描く。ビルドは不要（HTML と JavaScript だけ）。

## 遊び方の流れ（企画の図のとおり）

- シングル → 難易度（初級／中級／上級）→ 対AI：上か下の片方だけを描く。残りはAIが描いて合体する
- 対戦 → 難易度 → オンライン：同じ難易度で待っている部屋に自動で入る。なければ部屋を作って待つ
- フレンド → カギを入力 → 対戦：10けたのカギで友だちの部屋に入る
- フレンド → 部屋を作る → 難易度 → カギ：部屋ができて、10けたのカギが出る

部屋では、2人以上いて全員が「準備OK」を押すと始まる（最大4人）。描く時間は180秒。

分け方は難易度で変わる。同じ難易度の中からランダムに1つ選ぶ（一覧の図は `layouts.jpg`）。

- 初級：横に分ける、縦に分ける
- 中級：ななめ（2〜4人）、上と下の左右・左と右の上下（3人）、田の字（4人）
- 上級：ギザギザの横と縦（2〜4人）、まんなかと外側（2人）、Y字（3人）、×字（4人）

シングルは2つに分けて、片方をAIが描く。

## 手元で動かす

```bash
python -m http.server 5173 --directory oekaki-web
```

ブラウザで `http://localhost:5173` を開く。`?sec=15` をつけると、描く時間を15秒にできる（確認用）。

## Supabase をつなぐ

設定前は「お試しモード」で、対戦とフレンドは同じブラウザの別タブ同士だけつながる。

1. Supabase でプロジェクトを作る
2. SQL Editor に `supabase/schema.sql` を全部貼って Run を押す
3. Project Settings → API の Project URL と anon public key を `config.js` に貼る

`service_role` の鍵は貼らない。

## 守りのしくみ

サーバー（Supabase）側：

- `rooms` の表は、外から直接読む・書く・消すことができない。`schema.sql` の窓口の関数だけが使える
- 人数の更新と部屋を閉じる操作は、部屋を作った人だけが持つ合言葉が必要
- カギは10けた。まちがったカギを同じ接続元から1分に10回入れると、しばらく受けつけない
- 部屋を作れるのは、同じ接続元から10分に20部屋まで。使われている部屋が全体で500を超えたら断る

部屋の中（ブラウザ同士）：

- プレイヤーごとに、ページを開くたびに鍵のペアを作る。id は公開する鍵から計算するので、他人になりすませない（`sec.js`）
- 「始める」と「パート」のメッセージには署名をつける。署名が合わないもの、部屋にいない人からのものは捨てる
- 「始める」の中身も確かめる：お題と分け方は決まった一覧の中だけ。自分が「準備OK」を押していないラウンドには参加しない
- パートは本人のぶんだけを受けつけ、最初に届いた1つだけを使う（あとから書きかえられない）
- 席は来た順。あとから来た人が、前からいる人の席をうばったり追い出したりはできない

ページ：

- プログラムは自分のサイトのものだけを動かす（Content-Security-Policy）。通信の部品も `vendor/` に置いてある
- なまえなどの文字は、いつも「ただの文字」として表示する（プログラムとして動かない）

防げないこと：

- だれでも入れる「対戦」の部屋に、変な絵を描く人や、わざと何もしない人が来ること
- 部屋に入った人が、にせの参加者を何人も入れて席をうめること
- 大量の通信を送って、Supabase の無料枠を使い切らせること（Supabase 側の制限で止まるが、その間は遊べなくなる）

## ファイル

- `app.js`：画面とゲームの流れ
- `draw.js`：線を描くキャンバス、分け方（レイアウト）、合体のアニメーション
- `net.js`：部屋の通信（Supabase とお試しモード）
- `sec.js`：なりすまし対策（鍵のペアと署名）
- `vendor/supabase.js`：通信の部品（supabase-js 2.45.4 をそのまま置いたもの）
- `fx.js`：効果音、紙ふぶき、らくがきが流れる背景
- `card.js`：保存・シェアする画像（絵に背景・タイトル・お題・描いた人をつける）
- `ogp.png`：URL を貼ったときに出る紹介カードの画像（`tools/make_ogp.py` で作る）
- `style.css`：見た目（色、ボタン、アニメーション）
- `ai.js`：シングルでAIが描く絵（14種類）
- `topics.js`：難易度とお題
- `config.js`：Supabase の接続先
- `supabase/schema.sql`：Supabase に作るテーブルと関数
